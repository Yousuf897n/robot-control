# 🎨 محمد یوسف - Professional Portfolio Website

ایک جدید، خوبصورت اور مکمل طور پر responsive portfolio website جو HTML، CSS، اور JavaScript سے بنی ہے۔

## ✨ خصوصیات

### 🎯 مرکزی Features
- ✅ **Fully Responsive** - سب سے چھوٹے فون سے بڑے desktop تک
- ✅ **Dark Mode** - رات کی وضع اور دن کی وضع
- ✅ **Smooth Animations** - خوبصورت اور مربوط حرکتیں
- ✅ **Professional Design** - کاروباری اور ماہرانہ ڈیزائن
- ✅ **SEO Optimized** - سرچ انجن کے لیے موثر
- ✅ **Fast Performance** - تیز رفتار لوڈنگ

### 📱 صفحات اور حصے

1. **Navigation Bar** - آسان نیویگیشن
2. **Hero Section** - شاندار سرورق
3. **About Me** - اپنے بارے میں
4. **Projects** - 6 منتخب projects
5. **Skills** - تمام مہارتیں
6. **Contact** - رابطہ کرنے کا فارم
7. **Social Links** - سوشل میڈیا
8. **Footer** - نیچے کی معلومات

## 🐛 Troubleshooting

### سائٹ لوڈ نہیں ہو رہی؟
- Cache صاف کریں (Ctrl+Shift+Delete)
- Refresh کریں (Ctrl+R یا Cmd+R)

### Dark Mode کام نہیں کر رہا؟
- JavaScript enable کریں
- Console میں errors دیکھیں (F12)

### Mobile پر غلط لگ رہا ہے؟
- Viewport meta tag چیک کریں
- CSS میں responsive rules ہیں
